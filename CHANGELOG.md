# Changelog: v0.9.0 to v1.0.0, the conformance journey

One short bullet per change, newest first. A fix names its GitHub issue as `(#123)`.

## Unreleased

- internal: elaboration no longer writes the parser's AST. It writes an overlay (`Ast.SourceFile.overlay`) whose names, expressions and statements number on from the parse's, so every id and diagnostic is unchanged (ARCHITECTURE.md Phase 12). An embedder that sets `builtin_modules` and the other caller-set fields on a parsed file can pass them to `overlay` instead. No output changes.
- internal: codegen's per-value and per-block plan flags (`plan/unit.zig`: `needed`, `inlined`, `file_dep`, `loop_recompute`, `blk_work`, `blk_phi`, `dead_branch`) are bitsets, one bit per row instead of one byte. No output changes; compile time and peak memory unchanged on mos1, bsim4va, psp103 and hisimhv.
- `log10` of a subnormal argument is right: the 2^54 rescale used only the high word of the scaled value, 3.75 million ulp off at 3.74e-309 (#60).
- A batched testbench (the fixture suite's) mutes the §4.3.2 domain report while its self-checks probe points no analysis asked for, as a single testbench already did; `158_pow_negative_base_runtime_exponent` runs again (#59).
- A device's kernel banners name the files the kernels are in now (`lib/kernels/*.zig`, not `lib/backend/kernels/`); only those comment lines of the emitted text change.
- internal: `lib/ir`, `lib/analog` and `lib/prove` headers list the clauses their code cites, and comments name `names.zig`, `lib/device/codegen` and functions that exist; the unread aliases `Lower.Contribution` and `Lower.TpBlock` are gone (`Lowered`'s remain). No output changes.
- internal: the frontend, `base`, `diag`, `dynlib` and `elab` lose an unused import, a test wrapper and the never-built `ParamsetOverride.Kind.output_var`, and gain file-header and doc comments; no output changes.
- internal: the runtime sweep (`src/`, `lib/digital/`, `tools/`, the harness) drops the `sim.fmt`, `rt.State.Spec` and `cli/report.readFailed` aliases nothing needed (an embedder that read `sim.fmt` reads `kernels.fmt`), and fixes comments that named moved files or removed bounds. No output changes.
- Internal: the `device`, `exe` and `zigbuild` modules lose dead imports, write-only fields (a probed slot's `Place` is 12 bytes, was 16), forwarding wrappers, three unread `zigbuild` aliases (`Artifact`, `strip`, `splits`) and `pub` on 31 decls only their own file calls; comments name `ir/names.zig` and the current functions. No output changes.
- Three fixtures that no conforming run could pass now say what they mean: two `//! reject` lines quote E1157's and the `$realtime` refusal's current wording, and `last_crossing_in_creating_step` writes its expected time in digits.
- `Lowered` no longer holds the AST: what the backends read through it is precomputed by lowering (`default_transitions`, `timescale`, `decl_attrs`, folded `ParamInfo.ranges`), and the `ir` `module_specs` row imports only `base`, `diag` and `kernels`; `verilog` drops `frontend` and `elab` imports `base` (ARCHITECTURE.md Phase 11; row changes, released with 0.10.0). An embedder that read `lowered.file`, `.module`, `.unit_paths` or `.directives` reads `CompileResult.file`, `.module`, `.unit_paths` or the new rows; `vpi.open` takes the `CompileResult`, `Lower.lower` returns a `Lower.Output`, and `ir.Elaborate` is `vera.Elaborate`. `Ast.Type`/`Direction`/`ExprId`, `Preprocessor.Region`/`Timescale` and `Elaborate.Inserted`/`ParamOverride`/`DisciplineResolution` are aliases of `base`'s. No change to emitted text.
- Fix: §4.5.10 `last_crossing()` reports a crossing at the point that creates it (V(p) - 0.25 rising from -0.25 at 0 to 0.75 at 1n reads 0.25n at 1n, not -1), in every host; a device using it emits a different `eval` (#54).
- Fix: a `.v` `--emit-exe` executable that embeds the interpreter (a design not made native) exits 1 after a `$readmem` load §17.2.9 terminated (E1157), as `vera --run` does; it exited 0 (#65).
- The `backend` `module_specs` row is gone, split into `device` (`lib/device/`: codegen), `verilog` (`lib/verilog/`: `--emit-verilog`) and `exe` (`lib/exe/`: the testbench runner text), none of which imports another (ARCHITECTURE.md Phase 8; a row change, released with 0.10.0). An embedder's `dep.module("backend")` becomes one of the three; `vera.codegen`, `vera.beh_verilog` and `vera.tb` keep every name they had. The stable-name rules are `ir.names` (from `backend.naming`), which also spells every field name lowering, codegen and the testbench share (`__1b`, `__w<k>`, `__xz`, `__held__`). `zig build test-backend` is now `test-device`, `test-verilog` and `test-exe`. No change to emitted text.
- Fix: discipline resolution is linear in the instance count: a net reached through many instances of a module whose port has no discipline (2048 of them) elaborates in 0.03 s instead of 34 s, with the same answers (#75).
- Fix: in the analog context `%d` and a bare number are sized as IEEE 1364 §17.1.1.3 (and the digital engine) size them: `$strobe("%d", k)` of an `integer` prints 11 columns (`        -42`), a real 20, a sized literal or `reg` its own width, a comparison one; `%0d` prints the digits alone. A device's `say` records the same field (`%11d`). It printed minimal width before (#61).

Device text changes: ln, sqrt, ln1p, log and pow are spelled through checked kernels (`zLnD`, `zSqrtD`, `zLn1pD`, `zLog10D`, `zPowK`), whose check is empty in a solver device (#59).
- Fix: `limexp(x)` is `exp(x)` at every argument, as §4.5.13 requires of a converged point ("the simulator can only converge when the output of limexp() equals the exponential of the input"); past 80 it was the tangent e^80·(1 + x − 80), so a junction biased past 80 Vt converged to a current up to orders of magnitude too small. Device text changes: limexp emits exp's text, so a limexp device can now be `batch_ok`, and a unit whose limexp argument is unbounded compiles `.strict` with W0650, as exp does. Models that relied on the tangent for convergence should limit the junction voltage with `$limit` (VD-121) (#52).
