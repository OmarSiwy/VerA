# Updates past v1.0.0, bugs & performance

One short bullet per change, newest first. A fix names its GitHub issue as `(#123)`.

## Unreleased

- Fix: VPI analog (§12.10): the flow of an instance's unnamed branch over a node pair other instances also drive is that instance's own share of the summed row, no longer refused SHARED; a device built with `Options.vpi_contribs` publishes the shares as the optional `vpiShares`/`vpi_share_row` (`Lowered.contrib_shares`). A flow source's flow in a transient now includes the time derivative of its reactive half, which `vpiContribs` reported as 0, and the flow of a named branch another instance contributes to (§5.6.8.2) reads its row instead of SHARED. `p03_07_derivtf_partials.c` passes; `p03_13_reactive_branch_flow.c` is new (#20).
- Fix: a `.v` executable built with `--state=2` (`--two-state`) whose runtime reads a watched select's bits (`State.bits`) compiles; it failed with "variable of type 'comptime_int' must be const or comptime" (found by the book's `digital/xstate2` transcript) (#27).
- User documentation: an mdBook site (`docs/`, `mdbook build docs` in `nix develop .#docs`) that teaches Verilog-AMS chapter by chapter, documents `vera` (install, command line, `//!` directives, diagnostics, vendor attributes, `$limit`, implementation-defined choices, external suites) and the device contract for simulator authors, and includes the measures `tools/conformance.py` prints. Every transcript a page shows is a `.out` file `tools/doctest.py` re-runs, and CI fails on drift; the bench workflow publishes the book at the Pages root and the report at `/report/`. README rewritten to link to it. The LRM, the clause audit, the decisions, the measurements and the charts move to `specification/` (#27).
- `vera --emit-osdi` refuses a device with `$vera_reject_step` (E1099: OSDI 0.4 cannot carry a step-rejection request) and warns when one noise generator feeds two rows (W1098: the library reports them as independent sources); what an OSDI library leaves out is VD-102. `zig build test` now builds an `.osdi` (#24).
- The external suites gate by name: `tools/external_analog.py` and `tools/external_digital.py` pass a disagreement only when a row of its suite's `TRIAGE.md` covers it (an fnmatch pattern, one row per root cause) and fail on a row that covers none (STALE); CI jobs `external-analog` and `external-digital` run them in the new `nix develop .#external` shell, which carries the reference tools without the GPU toolchains (#24, #25).
- Tests for the digital fixes the ivtest triage made: a `#(min:typ:max)` procedural delay (A.6.5), a fork/join inside a recursive automatic task (each activation waits for its own arms, §9.8.2, §10.2.3), `%v` of a net driven only through a `tran` (§7.11, §17.1.1.5), and a constant function called in a generate condition (§10.4.5) (#25).
- Nix: CI runs `nix flake check` and builds the package on a runner of each system the flake lists (x86_64/aarch64 Linux and Darwin) (#26).
- Fix: a null argument of a display, file or string task (`$swrite(s, "a",,"b")` is `"a b"`) writes one space (§9.4.1) instead of nothing; `%s` prints a null argument it consumes as that space, any other conversion over one is E0819 (VD-101), and a null file descriptor is E0888.
- Fix: in a mixed module, `wire (strong1, pull0) w = a;` and `wire #(2, 6) w = a;` on a net with no discipline are continuous assignments (IEEE 1364-2005 §4.4.2, §6.1.3), no longer refused as §3.6.3.2 nodesets (E0365).
- Fix: a `time` variable a digital process writes, a top-level `output time` port included, is the digital engine's in a mixed run, where its assignment failed E1100.
- Fix: a string variable or parameter under an arithmetic, bitwise, shift or comparison operator with a number (`s + 1`, `s == 65`, `s & 1`, `-s`) is E0321 or E0322 (§3.3 Table 3-3), even when its value is a known literal; a string literal is still its Verilog number (`"A" + 1` is 66).
- Fix: `$mfactor`'s flow rules reach a named branch (§6.3.6): a contribution to `I(br)` is multiplied by `$mfactor`, an `I(br)` probe divided by it, and white or flicker noise on `I(br)` has its power multiplied (it was divided).
- Fix: a module's own `I(<a>)`, or `I(pb)` over its port branch, read inside an instance is refused by name (E0997) instead of reading the top port's flow or E0508 (§5.4.3); read `I(<u.a>)` from the module above.
- Fix: Annex A text VerA took and the grammar refuses (the grammar oracle's remaining vera-bug rows) is refused by its production: an empty argument or, in an analog expression, an empty list in a user function call (`f(, 1.0)`, `Vp(, n)`, `Ip()`; E0289, A.8.2); a declaration in an unnamed block, analog or digital (E0290, A.6.3; the digital refusal was E0209); `input real x;` in an analog function (E0291, A.2.6: type the formal by its own item); a net list mixing `p = 1.5` and `n` (E0292, A.2.1.3); a module instance with no name, `child(s);` (E0293, A.4.1; it was dropped with a warning); a `;` among an analog function's items (E0219); `supply1 supply1 s1;`, `pulsestyle_onevent (y);`, a literal assignment target (`#d 20 = 1'bx;`) and an `output` formal of a function without `analog` (E0207); a VAMS 2.x `{...}` concatenation as a `laplace_*`/`zi_*` coefficient vector (E0572: write `'{...}`, or leave the zeros empty); an empty enable slot, `timer(0, 1n, 1p, )`, and a string-typed monitored-event operand (E0517; a string literal stays §2.7's integer, VD-107). Fixtures that spelled these forms now spell the legal one, wants unchanged. `ddt (* vera_lte *)` and `absdelay (* vera_interp *)` are classed as the documented extension they are.
- `sim.spice` (`zig build test-spice`): the operating point falls back from plain Newton to dynamic gmin stepping, then to source stepping, as ESPice and ngspice do; `.noise ... dec|oct` sweeps run on SPICE's fixed-ratio grid; a `PsdTerm.corr_with` link between two noise generators adds its correlated cross term; the `tests/fixtures/external/` decks are left to their own runner (`tools/external_analog.py`) (#22).
- Every Annex E independent source (and a `--spice` V card that controls an F or H) multiplies its value by `$simparam("sourceScaleFactor")`, 1 unless a host steps it (VD-108); the devices of designs that use them gain the `source_scale__` Model field (#22).
- `--spice`: a `.subckt` may declare parameters (`PARAMS: k=v`, also unwritten) and its cards may use `{expr}`/`'expr'` values over them; an X card instantiates a subcircuit or module; a card naming a binned model (`.model name.N ... lmin= lmax= wmin= wmax=`) takes the bin that holds its L and W; node 0 inside a subcircuit is the ground. What is still not read is refused at the card (E0928): `.param`, nested `.subckt`, an expression with another function or operator, a bin no card's L/W picks (#9).
- A `noise_table`/`noise_table_log` whose knots are model parameters keeps its own sorted copy of the card's knots in the `Model` row (`noise_table_points__`, written by `derive`), so it survives row sharing and copying to a GPU; a host reads every table through `contract.noiseTable(D, &model, k)` (ESPice #9). `//! noise ... psd=<f>:<S>,...` asserts the table's density at given frequencies.
- `$simparam$str("cwd")` and `("analysis_name")` (§9.15 Table 9-28) can reach a device a host copies to a GPU or binds with numbers only: the host puts the strings in `contract.host_strings` and writes their indices into the `Model` fields `cwd_idx__`/`analysis_name_idx__` (0, the default, keeps the `Instance.cwd`/`analysis_name` slices) (VD-110, ESPice #10).
- §4.6.3: an `ac_stim` whose name is not "ac" or "noise" is active in the small-signal analysis the host labels with that name (Table 9-28 `analysis_name`, `contract.acStimActive`; VD-109), and `ac_stim("tran")`/`("dc")` no longer fire in a large-signal analysis; VerA's VPI AC sweep skips a stimulus of another name (ESPice #10).
- `vera --run` evaluates a `.v` design's timing checks (IEEE 1364-2005 §15): `$setup`, `$hold`, `$setuphold`, `$removal`, `$recovery`, `$recrem` (non-negative limits), `$width` and `$period`, with edge-control specifiers, `&&&` conditions and vector or constant-select terminals; a check's first violation is warning W1199, and every violation toggles the notifier (VD-103 to VD-105), and a VPI application's cbTchkViolation callbacks run, with obj the check. `$skew`, `$timeskew`, `$fullskew`, `$nochange`, a negative `$setuphold`/`$recrem` limit and their delayed signals are refused by name (E1149) instead of ignored under W0251; a negative or non-constant limit is E1148 and a notifier that is not a reg E1147. A VPI put of a check's limits changes what it judges by. W0251 in a digital run is now about path delays and pulse controls only. Both compiles now refuse (E0207) an empty mandatory timing check argument, an edge or `&&&` on an argument that is no event, `edge` with no descriptor list, and `$width (negedge clr, lim, , notif)` (§15.3.4).
- VPI `vpi_sim_control(vpiReset, stop_value, ...)` resets the digital run to time 0 (IEEE 1364-2005 C.7, VD-106): every reg and net at its initial value, every scheduled event cancelled, then the run goes on (nonzero stop_value) or ends; registered callbacks stand.
- Fix: legal Annex A syntax a `.va` refused (the grammar oracle's vera-bug rows, `tests/fixtures/GRAMMAR-DIFF.tsv`): min:typ:max in parameter, specparam and defparam defaults, named overrides, delays, path delays and timing-check offsets, read as the typical value (VD-099; in an analog expression it is E0295); null ports, `module m(a, , b)` and `.x()`, with named connections bound by a port's external name (A.1.3, §6.5.5); `reg signed` and `reg <discipline>` (E0371 when undeclared); a digital `function`'s `automatic`, `signed [range]`, `realtime`, `time`, `reg` and untyped formals, no longer held to the analog-function rules E0225 and E0510 (recursion); `$root.` in defparam, net, `disable`, lvalue, event and call names, `@ c.e`, `disable a.b` and `c.t;`; a concatenation as a switch, pull or UDP output terminal; a part-select or `+:`/`-:` branch terminal, a vector branch (E0352 when reversed or out of range); `inst.branch(t[i])` and `inst.branch(<p>)`; intra-assignment `@*` and `repeat (n) @*`; a null statement in an analog event block; `driver_update` in any digital event (E0818 outside a connect module).
- Fix: a held string variable owns its text, so a `$sformat` result held across evaluations no longer changes when its site runs again, in a later iteration, a rejected step or another instance (#19).
- Fix: a `$table_model` data-source capture stays with the instance only once an accepted iteration made it: a capture made in a rejected step or a discarded Newton iterate is undone, and the next first call captures again (VD-095) (#18).
- A device's `$debug` can show every Newton iteration: a host calls `say` after each iteration with `contract.Say.pass = .iteration` and at the accepted point with `.accepted`; VerA's `--display=record` testbench does (#10).
- Fix: a hierarchical name that opens an unnamed generate block from outside it (`genblk1.u.r`) is refused as E0998 (§6.6.2); a named block (`g1.u.r`) resolves as before (#13).
- Fix: an upward `defparam` (to an ancestor, the declaring instance, an earlier sibling or a top-level parameter) is applied, collected before the flatten binds its target (IEEE 1364-2005 12.8.1), instead of E0907; a value that reads a parameter elaborated after the target is still E0907 (#14).
- Fix: a far link of a paramset chain may read its own parameters (`.j = jval;`), which was E0314 (§6.4.1).
- Fix: `I(<u.p>)` is the flow into instance u through its own port, not the flow of the net the port is joined to (§5.4.3); one VerA cannot sum exactly is E0997.
- With `` `include "disciplines.vams" `` (or `"discipline.h"`), a base nature whose access function is Annex D's (`V`, `I`, ...) is E0335; without the include it is legal (VD-096, §3.13.2).
- Fix: a connect module is placed from the elaborated subtree below its level: a generate block, an instance array, a paramset instance at any depth or an out-of-context declaration below the planned level now decides the upper connection's domain instead of being refused (E0929), and a generate block's own mixed port gets its bridge (#11).
- Fix: a part-select above bit 31 of a wide `reg` read in the analog context reads exact bits (a digital process's `reg` reaches the device one 32-bit word per `Model` field; a literal-only `reg` folds), no longer E0329; a select of a mixed module's `reg` input works at all (#12).
- Test: Figure 7-6 Case 2, detail-merged, asserts two connect modules (§7.8.4's merge rule, VD-092) (#23).
- Fix: a child's `output reg` port connected to a discipline-less parent `wire` (an inserted connect module's included) is no longer E0362 (§6.8: two scopes).
- Fix: the mixed runner runs the `analog initial` block before the digital `initial` blocks (§8.4.1), so a digital read of a continuous variable at time zero sees what it assigned.
- Fix: VPI analog (§12): an analog system task's calltf may put a value and its declared partials on an argument that is a real or integer variable, and the design reads it back after the call (§12.22.2's `$resistor`; `contract.Systf.outs`, `SystfHost.out`); a put on any other argument is refused (NOPUT); the VPI host runs `ac` sweeps (§12.8 frequency, §12.10 imaginary parts; VD-098), and every `.c` fixture now runs under `zig build test` (#20).
- A device publishes its module's `desc`/`units` attributes (§2.9.2) as the optional `decl_meta` table (`contract.DeclMeta`: parameters, output variables, nets), for a host's help messages and operating-point reports; fixtures assert it with `//! meta` (#15).
- `//! noise ... corr=<j>:<rho>` asserts §4.6.4.6's correlation coefficient between two published noise rows, so anti-correlated sources (one generator, opposite signs) are testable (#17).
- Fix: a digital `$monitor` that reads an analog probe (`V(net)`) crashed the mixed-signal engine; it now reports after each digital time step's analog solve when a probed value moved (§8.5.1), and a probe in a continuous assignment or `@*` is refused (E1100) instead of crashing (#16).
- Fix: a digital `$monitor` that reads an analog probe also reports at an analog solution no digital event shares, at that solution's time rather than the next digital event's (§8.4.3.2, §8.5.1), and reports when a probe moved, so `$realtime` advancing inside an argument no longer prints a line (VD-111) (#16).
- `//! reject-run <code>` pins a run-time refusal in a `.va` fixture: the testbench must exit nonzero with that `error[...]` line and no other (#21).
- Testing framework (`docs/TESTING.md`): a requirement ledger of the LRM's normative sentences (`tests/fixtures/OBLIGATIONS.tsv`, `conformance.py obligations`) that fixtures cite as `//! lrm <clause>:<n>`; `//! reject-only` (exactly one error) and `//! neighbour` (the legal variant that must compile); a verdict ratchet (`tests/fixtures/VERDICTS.tsv`), a build-step inventory (`tests/STEPS.txt`) and `lint-cites`, each a bench gate; canary fixtures the harness must judge wrong (`zig build test-canary`); want perturbation, derivative, finiteness and state certificates (`benchmark -- --perturb`, `--certify`, `//! fd-exempt`); a MIR verifier after lowering and each MIR pass in Debug and ReleaseSafe; in-process fuzzing (`zig build fuzz`); the Annex A grammar oracle; the Icarus differential and the mutation run; and `test-rng-reference`, `test-printf-reference`, `test-suite` and `test-all`. `--coverage` counts bare clause cites only (a sentence cite is the ledger's).
- Fix: VPI (§12): vpiStop, vpiSetInteractiveScope (firing cbInteractiveScopeChange), vpiTransientFailConverge and vpiAnalogTime are defined and answered, cbAssign/cbDeassign/cbDisable are delivered, channel 3 is a product log file the host names (`vpi.setLogFile`) and vpi_printf writes it, a put keeps a module path's pulse limits, vpiNoDelay onto a sequential UDP sets it, vpiObjTypeVal on a time variable is vpiTimeVal, and a vpiIntFunc analog systf's call is an integer (`Options.int_systfs`; the startup routines now run before the device is built). A device's `systf_calls` is one entry per call site (`contract.Systf.tok`), so one function called from two sites runs its calltf at each.
- Fix: hierarchy (§6): a hierarchical name searches upward (IEEE 1364-2005 12.6/12.7), a loop generate's instances are elaborated once per genvar value as `blk[i].inst` (§6.6.1) and select their paramset with those values (§6.9.2), a genvar the iteration does not assign or set to x is refused (E0419, E0486), a port connects to a constant bit- or part-select of a net (§6.5.5), a paramset's statements run after the module's analog blocks so its output variables are reported (§6.4.3), and a paramset with no item declaration is E0297 (A.1.9).
- Fix: an omitted argument (`f(a, )`, `$limit(x, )`, a pattern hole) is E0894 or E0505 instead of a crash or a silently shortened call (A.8.2).
- Fix: `ddt_nature` is checked like `idt_nature` (E0374), an incompatible hierarchical discipline override is E0375 (§3.6.2), `initial_step`/`final_step` in the digital context is E0708, `$fatal` with a finish number other than 0-2 is E0824, a string operand of a §4.3 function, a `$sscanf` source that is not a string, a string returned from an integer function, a write to an array parameter, and a packed vector assigned to an array are refused.
- Fix: `initState` resets every field `updateState` advances, so a new analysis re-initializes held variables and operator history (§4.6.2); a host-visible contract change.
- Fix: `$mfactor` scales flow noise power by m and potential noise power by 1/m (§6.3.6); a monitored `cross`/`above` honours both `expr_tol` and `time_tol`; `%l` prints `work.<cell>`; a `$sformat` with a run-time format formats at run time; `$error` in `analog initial` stops after initialization; `$rdist_*` domain errors report E0816 and exit 1; a non-numeric `$table_model` entry errors at the first call; the testbench Newton solver judges pivots per row.
- Fix: a `--spice` card value with a scale suffix (`50n`, `2.2p`) is the double nearest the literal, as a §2.6.2 literal is, not one ulp off (#9).
- Nix: `nix run github:OmarSiwy/VerA`, release binaries as `.#"1.0.0"`/`latest` (`sources.json`), `overlays.default`, and `nix flake check` in CI.
- `tools/external_analog.py`: the external analog suites under `tests/fixtures/external/` (hand-derived OSDI decks, VA-Models against OpenVAF-Reloaded, the CMC and TU Dresden QA references, Xyce), run in `nix develop .#benchmarking`; CI job `external-analog` reports their FAIL names.
- `` `include "discipline.h" `` and `"constants.h"`, the Verilog-A 1.0 names of the Annex D headers, now resolve to the built-ins (VD-093) (#4).
- `vera --emit-osdi FILE.va -o out.osdi`: an OSDI 0.4 library ngspice loads with `pre_osdi` (`tools/osdi_dyn.zig`), the same device `--emit-so` builds.
- Fix: a device built for a simulator no longer drops its `$strobe`/`$display`/`$write`/`$debug`/`$warning`/`$info` (W0850): it publishes `say_sites` and `say`, which a host calls once per accepted point to collect records into a buffer it lends (`contract.Say`) and prints with `contract.formatSay`; VerA's testbench (`--display=record`) and `sim.spice` print them, `--display=drop` keeps the old device, and W0850 now names only what is still dropped (`$monitor`, `$finish`/`$stop`, file tasks) (#10).
- Fix: a `--spice` `.subckt` may hold M, Q, J and D cards: each instantiates its model, a `.model`'s Verilog-A module type (BSIM-CMG, BSIM4, ...) with the card's parameters over the model card's and `M=` as `$mfactor`, or a module of that name; `.include`, `.lib file entry` and `.hdl` are read, netlist names match the design's regardless of case, and a card whose model is a behaviourless Table E.1 `nmos`/`npn`/`d` is refused at the card (E0953) (#9).
- Fix: a hosted `.v` device prints its `$display` output (to stderr) for each step the host accepts; a rejected step prints nothing, and a step past 4096 bytes is cut (#8).
- Fix: a `.v` device holds up to 65535 pins (was 256), and past 64 its `deriv_reads`/`ddx_reads`/`jac_pattern` are declared in `contract.MaskOf(|U|)`: one derivative lane per output row instead of a dense Jacobian. The contract accepts any unsigned `U` tag of 8 bits or more; `contract.Mask(D)` is a device's mask type (u64 for every device that declares no wide mask) (#5).
- Fix: an `output reg` port connected to a bit-select, part-select or concatenation drives exactly those bits (IEEE 1364-2005 §12.3.9.2), no longer E1100 (#6).
- Fix: a digital task enable with arguments no longer reads freed memory once later source grows the parser's expression pool (a panic in `digital.compile.infer`) (#7).
- Fix: digital selects with an index wider than 64 bits now work under `--run` and `--emit-exe` (#2).
- Fix: native digital keeps a formatted scan's state across nested output calls (#3).
