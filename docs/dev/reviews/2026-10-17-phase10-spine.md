# Design review: Phase 10, the spine into `vera`

- **Change**: `src/main.zig`'s `compileAnalog` (and the E1099/W1098 OSDI checks) becomes `vera.compile` in `lib/root.zig`; `typeCheck` moves to `zigbuild`, `readFailed` to `vera`; `main` prints the returned `Outcome`.
- **Domain skill(s)**: `api-design` (the `vera` module is an embedder API), `codebase-clean-code` (spine), `zig`.
- **Hot/cold**: cold. Evidence: none; the spine runs once per process.
- **Stages run**: R1, R6, R7, R9 (a public-API change, AGENTS.md §10.1), R10.

## Boundary (R1)

Usage code, written before the API (an embedder that wants a device's text and a `.so` in one call):

```zig
var arena: std.heap.ArenaAllocator = .init(gpa);
defer arena.deinit();
var bag: vera.diag.Bag = .init(gpa);
defer bag.deinit(gpa);
var o: vera.Outcome = .{};
defer o.deinit();
try vera.compile(gpa, io, arena.allocator(), source, .{
    .options = .{ .file_name = "res.va", .include_dirs = &.{"models"} },
    .so = true,
    .zig = true,
    .build = .{ .contract = "share/vera/contract.zig", .dyn = "host_dyn.zig", .work_dir = "build" },
}, &bag, &o);
if (o.status != 0) return fail(o.err, &bag);
use(o.path.?, o.text); // the library, then the device text
```

- **Granularity.** `compile` is the coarse tier. Every step under it stays public: `compileSourceOpts`, `CompileResult.generateDevice`/`generateOutput`, `buildArtifact`, `tb.*`, `orchestrator.typeCheck`, `beh_verilog.emit`. An embedder that needs one step skips `compile` (the VPI hosts and `golden` already do).
- **Redundancy.** `compile` is the diagonal route over those calls; nothing below it was removed.
- **Coupling.** The bag is the caller's, the arena is the caller's, the `Outcome` is the caller's (filled even when `compile` returns an error, so `report` says whether the bag is final). No hidden state.
- **Retention.** None: `Outcome` holds the `CompileResult` only so `text` can borrow the device without a copy.
- **Flow control.** The caller's. `compile` prints nothing, runs no testbench (`--run` spawns in `main`), and writes only the `out_path` the request names.

## Test plan (R7)

| Bug class | Oracle | Layer | Harness |
| --- | --- | --- | --- |
| A stream byte or exit code moves | the pre-change transcripts | CLI | `tools/doctest.py`, `zig build test-cli`, `zig build golden` |

| `--param`'s refusal reports the first pass's warnings | `report == .none` in `test compile` | unit | same |

Exit criteria: golden IDENTICAL; `doctest.py` passes; `test-cli`, `test` exit 0; VERDICTS name list unchanged.
